Détail du produit

  • Module relais WiFi intelligent – design compact (55x29x17 mm)
  • Télécommande Bluetooth RM2.4G – 4 boutons numérotés, TOUT ALLUMER, TOUT ÉTEINDRE
  • Bornes de sortie relais : NO (Normalement Ouvert), COM (Commun), NF (Normalement Fermé) – contacts secs
  • Options d’entrée d’alimentation : Micro USB (DC 5V/0,5A) ou bornier (DC 7V-48V)
  • Bouton d’appairage – également appelé « Touche d’ouverture » pour l’appairage Wi-Fi
  • Voyant lumineux du relais – indique l’état du relais
  • Voyant lumineux du réseau WiFi – indique l’état de la connexion

Schéma de câblage

  • Entrée d’alimentation (DC 7V-48V) : Connectez le positif (+) à VIN, le négatif (-) à GND
  • Entrée d’alimentation (USB) : Connectez un câble micro USB (5V/0,5A)
  • Sortie relais (contact sec) : Connectez le circuit de commande de l’appareil à NO/COM/NF
  • Exemple : Pour un appareil DC avec DC 7V-48V, connectez la source d’alimentation à VIN/GND, l’appareil à COM/NO
  • Exemple : Pour un appareil AC/DC (1V-250V), connectez l’alimentation externe via COM/NO

Avertissement

  • Débranchez toujours l’alimentation avant d’effectuer tout câblage ou entretien.
  • Ne dépassez pas le calibre maximum du relais de 10A sous 250V AC ou 30V DC.
  • Assurez-vous que la tension d’entrée est comprise dans DC 5V (USB) ou DC 7V-48V (bornier).
  • Installez dans un endroit sec et bien ventilé, à l’abri de l’humidité et des températures extrêmes.
  • Faites appel à un électricien qualifié en cas de doute sur le câblage.
  • Le module prend en charge uniquement le Wi-Fi 2,4 GHz (ne fonctionne pas avec les réseaux 5 GHz).

Mode de fonctionnement

Le module prend en charge deux modes de fonctionnement principaux, configurables dans l’application eWelink.

Mode Impulsionnel (Momentané)

Lorsqu’il est déclenché, le relais s’active pendant une durée définie (0,5 à 3600 secondes) puis se désactive automatiquement. Convient aux ouvre-portes de garage ou aux appareils déclenchés par impulsion.

Comment configurer : Dans l’application eWelink, sélectionnez le mode Impulsionnel et définissez la durée souhaitée.

Mode Auto-maintien (Bascule)

Agit comme un interrupteur marche/arrêt standard – un déclenchement allume le relais, un autre déclenchement l’éteint. Convient aux lumières, ventilateurs et commandes continues.

Comment configurer : Dans l’application eWelink, sélectionnez le mode Auto-maintien.

Contrôle via l’application (eWelink)

  1. Téléchargez l’application eWelink (Android/iOS) depuis la boutique d’applications ou scannez le code QR.
  2. Créez un compte et connectez-vous.
  3. Allumez le module.
  4. Appuyez sur ’+’ pour ajouter un appareil.
  5. Maintenez enfoncé le bouton d’appairage sur le module jusqu’à ce que le voyant WiFi clignote rapidement.
  6. Suivez les invites de l’application pour vous connecter à votre réseau Wi-Fi 2,4 GHz.
  7. Une fois appairé, vous pouvez :
    • Allumer/éteindre les appareils
    • Définir des programmations et des minuteries
    • Configurer les modes de fonctionnement
    • Partager le contrôle avec les membres de la famille

Télécommande Bluetooth

La télécommande Bluetooth RM2.4G incluse permet une utilisation locale :

  • Boutons 1-4 – contrôlent les canaux de relais correspondants (ou fonctions)
  • TOUT ALLUMER – allume tous les appareils connectés
  • TOUT ÉTEINDRE – éteint tous les appareils connectés

La télécommande est généralement pré-appairée. Si un ré-appairage est nécessaire, suivez les instructions de l’application eWelink.

Commande vocale (Alexa / Google Home)

  1. Liez votre compte eWelink à Amazon Alexa ou Google Home via leurs applications respectives.
  2. Découvrez les appareils.
  3. Utilisez des commandes vocales telles que :
    • « Alexa, allume la lumière »
    • « Hey Google, éteins le ventilateur »

Entretien

  • Nettoyage : Essuyez avec un chiffon doux et sec. N’utilisez pas de nettoyants liquides.
  • Ventilation : Assurez une circulation d’air adéquate autour du module.
  • Évitez l’humidité : Gardez au sec et à l’abri de l’humidité.
  • Connexions sécurisées : Vérifiez périodiquement le câblage pour tout desserrage ou corrosion.
  • Mises à jour du firmware : Vérifiez l’application eWelink pour les mises à jour disponibles.
