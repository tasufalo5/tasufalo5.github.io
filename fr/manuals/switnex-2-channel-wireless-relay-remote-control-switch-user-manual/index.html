Détail du Produit

  • Carte récepteur – fonctionne en DC 5V-30V, comprend un voyant lumineux, un bouton d’apprentissage, une antenne
  • 2 x Émetteurs porte-clés – boutons métalliques, cadre chromé, fermeture coulissante pour éviter les pressions accidentelles, boutons A et B
  • Bornier : Grandes vis pour un câblage facile
  • Bornes du Relais 1 : NO1, COM1, NF1
  • Bornes du Relais 2 : NO2, COM2, NF2
  • Bornes d’alimentation : VIN (positif), GND (négatif)

Schéma de Câblage

  • VIN : Connectez le positif DC 5V-30V
  • GND : Connectez le négatif DC 5V-30V
  • NO/COM/NF : Contacts secs pour chaque relais (sortie passive)
  • Connectez le circuit d’alimentation de l’appareil via les contacts du relais (par exemple, source d’alimentation à COM, appareil à NO pour normalement éteint)

Avertissement

  • Débranchez toujours l’alimentation avant d’effectuer tout câblage ou entretien.
  • Assurez-vous que la tension d’entrée est comprise dans la plage DC 5V-30V et que le courant de charge ne dépasse pas 10A par canal.
  • N’exposez pas l’appareil à l’humidité. Les télécommandes ne sont pas étanches.
  • Gardez hors de portée des enfants.
  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, reprogrammez-les.
  • Réinitialisez avant de vouloir changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la pile à temps lorsque la tension de l’émetteur à distance est faible.

Mode de Fonctionnement

Le produit est généralement préprogrammé en Mode Bascule. Suivez les étapes ci-dessous pour changer de mode.

Mode Momentané

Appuyez et maintenez un bouton → le relais s’active
Relâchez le bouton → le relais se désactive

Comment programmer :

  1. Appuyez 1 fois sur le bouton d’apprentissage du récepteur. Le voyant lumineux s’allumera.
  2. Appuyez sur le bouton A de la télécommande. Le voyant lumineux clignotera une fois.
  3. Appuyez sur le bouton B de la télécommande. Le voyant lumineux clignotera une fois. Réussi.

Mode Bascule

Appuyez une fois sur un bouton → le relais s’active
Appuyez à nouveau sur le même bouton → le relais se désactive

Comment programmer :

  1. Appuyez 2 fois sur le bouton d’apprentissage du récepteur. Le voyant lumineux s’allumera.
  2. Appuyez sur le bouton A de la télécommande. Le voyant lumineux clignotera une fois.
  3. Appuyez sur le bouton B de la télécommande. Le voyant lumineux clignotera une fois. Réussi.

Mode Verrouillé

Appuyez sur le bouton A → Le relais 1 s’active, le relais 2 se désactive
Appuyez sur le bouton B → Le relais 2 s’active, le relais 1 se désactive

Comment programmer :

  1. Appuyez 3 fois sur le bouton d’apprentissage du récepteur. Le voyant lumineux s’allumera.
  2. Appuyez sur le bouton A de la télécommande. Le voyant lumineux clignotera une fois.
  3. Appuyez sur le bouton B de la télécommande. Le voyant lumineux clignotera une fois. Réussi.

Réinitialisation

Pour effacer toutes les télécommandes appairées de la mémoire du récepteur, appuyez 8 fois consécutivement sur le bouton d’apprentissage. Le voyant lumineux clignotera plusieurs fois puis s’éteindra, indiquant que toutes les télécommandes appairées ont été effacées.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Le récepteur ne répond pas à la télécommande : Assurez-vous que le récepteur est correctement alimenté (DC 5V-30V). Vérifiez la pile de la télécommande (A27). Vérifiez que la télécommande est appairée. Effacez et réappairez si vous n’êtes pas sûr. Réduisez les interférences RF ou les obstacles.
  • Le récepteur ne fonctionne pas en 5V : Certaines unités peuvent nécessiter 5,5V ou 6V pour un fonctionnement fiable. Essayez d’augmenter la tension d’entrée dans la limite de 30V.
  • La télécommande a cessé de fonctionner après une exposition à l’humidité : La télécommande n’est pas étanche. Ouvrez le boîtier, retirez la pile, séchez complètement. Remplacez si nécessaire.
  • Le relais clique mais l’appareil ne s’active pas : Vérifiez le câblage des bornes NO/COM/NF. Assurez-vous que l’appareil a sa propre alimentation. Vérifiez que la charge de l’appareil ne dépasse pas 10A.

Entretien

  • Gardez le récepteur et les télécommandes dans un environnement sec.
  • Évitez d’exposer les télécommandes à l’humidité ou au contact direct de l’eau.
  • Remplacez la pile de la télécommande (A27) lorsque la portée diminue ou que la LED devient faible.
  • Assurez-vous que les connexions de câblage restent sécurisées au fil du temps.
