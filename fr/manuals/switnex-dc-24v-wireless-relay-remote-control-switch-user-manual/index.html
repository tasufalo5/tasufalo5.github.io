Détail du produit

  • NO : Broche normalement ouverte
  • COM : Broche commune
  • NC : Broche normalement fermée
  • Bouton d’apprentissage sur le récepteur – pour les modes de programmation et la réinitialisation
  • LED indicatrice sur le récepteur – fournit un retour visuel
  • Antenne sur le récepteur – à déployer pour une meilleure réception du signal

Schéma de câblage

Avertissement

  • Généralement, le récepteur et l’émetteur sont appairés en usine. Sinon, vous pouvez les reprogrammer vous-même.
  • Réinitialisez avant de changer le mode de fonctionnement.
  • Après la réinitialisation, toutes les télécommandes ne fonctionneront plus.
  • Remplacez la batterie à temps lorsque la tension de l’émetteur est faible pour obtenir une transmission de signal plus forte.
  • Déployez légèrement l’antenne sur le récepteur pour une meilleure réception du signal.
  • L’émetteur doit avoir 3 boutons ou plus si vous souhaitez configurer le mode verrouillé.
  • Le type de sortie est une sortie passive / contacts secs.

Mode de fonctionnement

Mode Momentané

Maintenez enfoncé le bouton A → le relais 1 s’allume
Relâchez le bouton A → le relais 1 s’éteint

Comment programmer :

  1. Appuyez une fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Mode Bascule

Appuyez sur le bouton A → le relais 1 s’allume
Appuyez à nouveau sur le bouton A → le relais 1 s’éteint

Comment programmer :

  1. Appuyez deux fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Mode Verrouillé

Appuyez sur le bouton A → le relais 1 s’allume
Appuyez sur le bouton B → le relais 2 s’allume, et le relais 1 s’éteint en même temps

Comment programmer :

  1. Appuyez trois fois sur le bouton d’apprentissage du récepteur. La LED indicatrice s’éteindra.
  2. Appuyez sur le bouton A de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’éteindra.
  3. Appuyez sur le bouton B de l’émetteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Réinitialisation

Appuyez huit fois sur le bouton d’apprentissage du récepteur. La LED indicatrice clignotera plusieurs fois puis s’allumera. Réussi.

Dépannage

Si le récepteur et l’émetteur ne fonctionnent pas normalement, essayez les étapes suivantes :

  • Vérifiez si la batterie est épuisée. La LED indicatrice de l’émetteur ne s’allume pas ou est faiblement allumée.
  • Vérifiez si votre récepteur est correctement câblé. Il est important de s’assurer que le câblage est correct.
  • Reprogrammez le récepteur et l’émetteur. Cela résout généralement de nombreux problèmes.
  • Si le problème persiste, veuillez nous contacter rapidement. Nous ferons de notre mieux pour résoudre votre problème.
