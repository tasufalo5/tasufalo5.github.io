Welcome!

Welcome to the Docsy theme user guide! This guide shows you how to get started creating technical documentation sites using Docsy, including site customization and how to use Docsy’s blocks and templates.

What is Docsy?

Docsy is a theme for the Hugo static site generator that’s specifically designed for technical documentation sets and has a lot of best practices built in. Use Docsy to get a working and reliable documentation site up and running fast, and then get back to focusing on great content for your users. Learn more about Docsy.

SWITNEX

SWITNEX designs and produces RF-based remote switching hardware plus connected wall devices across Wi‑Fi, Zigbee and Bluetooth—built for installers who need dependable, low-friction control that stays economical to deploy. In-house manufacturing, application engineering and the SWITNEX product line support projects from access readers and door strikes to lighting, ventilation, signaling and small-footprint DIY retrofits. SWITNEX publishes model-level manuals, field notes and compliance-oriented explainers alongside the catalog story.
