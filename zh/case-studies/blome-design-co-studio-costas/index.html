探索简约与永恒背后的灵感，与Blome Design Co.合作的Studio Costas

Friday, January 28, 20221 分钟阅读

探索简约永恒背后的灵感：Blome Design Co. 与 Studio Costas 的故事

“我相信，完整的品牌体验是建立忠实客户群的关键。我希望赋能那些有意识的小企业主实现这一目标，同时引导他们的客户走向更美好的方向。"——Vina

来源： https://tendlyn.com/imprint/journey-into-the-inspiration-behind-the-simple-and-timeless-studio-costas-with-blome-design-co/ 作者： tendlyn 发布时间： 2022-01-28T00:00:00.000Z 阅读时间： 4分钟

在本系列中，我们将展示一些杰出的 tendlyn 创意人士及其值得关注的热情项目。通过深入探讨个人设计工作的过程与魔力，我们邀请创意人士分享是什么点燃了他们的灵感。本期专题，我们将聚焦 Blome Design Co. 打造的慢时尚品牌 Studio Costas 背后的故事。

“这个项目提醒我，作为创意人士，投身热情项目至关重要。滋养我们的创造力应始终是首要任务，因为它是我们业务中最宝贵的资产！投身于这样的热情项目，能让你发挥创意天赋，磨练技艺，形成独特风格，并吸引你梦寐以求的客户。"——Vina

Blome Design Co. 是一家位于新加坡的设计工作室，源于 Vina 对品牌设计的热情以及帮助有意识的企业主将愿景变为现实的初心。她将自己的工作与有意识的生活方式和健康领域相结合，这与她的个人兴趣不谋而合，让她能更深入地理解客户，与志同道合的人紧密合作也总是令人兴奋。

Vina 是 Blome Design Co. 背后的品牌与包装设计师，她与小企业主合作，为他们的受众打造富有策略且充满情感的品牌体验。她帮助他们理清业务思路，创建有意图的品牌，从而与客户建立真诚的联系。

“我喜欢与有意识生活方式领域的品牌合作，因为他们对业务的深思熟虑让我所做的一切有了意义。这也与我的个人兴趣高度契合，让我能完全理解客户，并通过品牌和包装将他们的愿景变为现实。我相信，完整的品牌体验是建立忠实客户群的关键。我希望赋能那些有意识的小企业主实现这一目标，同时引导他们的客户走向更美好的方向。"——Vina

Studio Costas 是一个虚构的慢时尚品牌，专注于为其系列采用高品质、可持续的材料。这个热情项目的灵感源于 Vina 自己整理衣橱的经历。她希望打造一个胶囊衣橱，里面装满简约而永恒的实用单品。这份渴望促使她创建了一个提供易于搭配的优质基础款的品牌，并激励他人打造精简衣橱——于是，Studio Costas 诞生了。

Vina 设想了一个能唤起系列中实用、永恒单品的品牌名称，以构建理想的叙事。她偶然发现了"Costas"这个词，在希腊语中意为"恒定、坚定”，并立刻爱上了它，因为这也让她想起了圣托里尼。她开始从这座岛屿迷人而独特的基克拉迪建筑中汲取灵感，这种建筑以其粉刷成白色、边缘圆润的造型和极简美学风格而著称。

建筑灵感与品牌打造极简、精致廓形的理念相呼应，贯穿于永恒系列之中。让元素紧密相连，并为 Studio Costas 品牌讲述一个引人入胜的故事至关重要：受田园诗般的希腊别墅启发，为精简衣橱提供永恒、优质的基础款。

——Vina

Vina 围绕品牌故事和相关关键词构建了一个情绪板，以传达品牌的视觉与感觉。希腊别墅基克拉迪建筑的拱形是她设计品牌标志和品牌标识的主要灵感来源。基克拉迪风格还从古希腊艺术中汲取灵感，这种艺术在公元前2000年蓬勃发展，并强化了 Costas 品牌的永恒与极简品质。

“大海和现代地中海风格的内饰启发我创造了品牌的调色板。整体调色板为 Costas 品牌营造了一种宁静而现代的外观。"——Vina

为了突出品牌的可持续性，Vina 精心挑选了环保包装和品牌应用。她选择了边角料制作服装标签，使用再生纸制作感谢卡和系列手册。

Vina 说道："正如你通过这个品牌的创作过程所看到的，品牌塑造远不止一个标志。品牌是一个与受众情感相连的故事。你的品牌故事、视觉识别和创意应用应协同作用，为受众创造完整的体验。”

Vina 在为一位客户寻找可持续包装方案时偶然发现了 tendlyn。她立即订购了样品包，并对其打印质量感到满意。从那以后，她一直向所有客户推荐 tendlyn，因为她坚信我们每个人都能在创造更可持续的未来中发挥作用，而这一切都始于我们自己的业务。

在结束这个精彩专题时，Vina 忍不住分享了项目中的一些感想：

“圣托里尼是我遗愿清单上的旅行目的地之一，而做这个项目感觉就像把自己传送到了那里。我玩得非常开心！我很享受情绪板策划的过程，并了解了迷人的基克拉迪建筑，这也是我该项目的主要灵感来源。"——Vina
