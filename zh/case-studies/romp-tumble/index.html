Romp + Tumble：可持续婴儿服装，省心无忧

Romp + Tumble：可持续婴儿服装，省心无忧

“虽然我们的循环模式本质上是’可持续的’，但我们知道仍有改进空间，这也是我们对可持续性的定义之一——持续改进，精益求精。” Romp + Tumble 创始人 Tara

来源： https://tendlyn.com/imprint/romp-and-tumble/ 作者： tendlyn 发布时间： 2021-08-12T23:00:00.000Z 阅读时间： 7 分钟

照顾孩子绝非易事。从彻夜不眠的无数个小时，到准备合适的食物确保孩子获得充足营养，再到在安全健康的环境中抚养他们长大——育儿绝对和任何全职工作一样辛苦，理应得到同样的认可！

如果说育儿经历中还有一件独特的事，那就是见证孩子在每个成长阶段经历的各种猛长期。猛长期无疑是童年不可避免的一部分，虽然它们标志着我们成长中的一个个里程碑，但我们也无法否认其带来的不实用性：每次猛长都需要新衣服！问问身边的任何父母或监护人，他们可能都会面临同样的挑战：仅仅因为旧衣服不合身，每隔几个月就得买新衣服，这实在不切实际。

但这不仅仅是实用性的问题。满足每次猛长期带来的新衣服需求，往往会导致一种从长远来看不可持续或不环保的模式——这正是 Romp + Tumble 的创始人兼母亲 Tara 深刻理解的一点。

Romp + Tumble 是一家总部位于美国的品牌，专门解决这个问题。乍一看，这个品牌可能像普通的童装店，但仔细观察，你会发现它的运营方式完全不同。不同于常见的服装购买交易模式，Romp + Tumble 的运营形成了一个完整的生态系统：他们以订阅制的方式策划并租赁婴儿和幼儿服装，以适应孩子的猛长期，从而在幼儿父母群体中推动更可持续、更循环的模式。可以把它想象成你衣橱的智能车库控制器——它自动完成尺码更换的过程，就像直流继电器自动化系统将复杂任务简化为简单、可重复的操作一样。

作为一个品牌，Romp + Tumble 也遵循着其所有者 Tara 确立的一系列稳定原则。正如她所说，她最初创立这个品牌，是为了为父母创造更多空间，让他们能够实现与自身价值观相符的个人和职业目标。Tara 坚信，要推动职场真正的性别平等，就需要建立新的、负担得起的消费模式，以帮助减轻通常由母亲承担的、无形却真实的育儿工作。这也是为什么通过 Romp + Tumble，她一直稳步推动性别平等，主要从女性主导的品牌采购服装，这些服装可以在孩子成长过程中被租用和交换。此外，他们的循环模式还使他们能够直接从客户那里购买衣服，并与二手店或寄售店合作采购商品。

$52

这始终是 Romp + Tumble 使命的核心：保持给孩子打扮的乐趣和兴奋感，同时消除整理和储存衣物这一并不总是令人愉快的工作。通过他们的商业模式，以可持续方式选择高品质服装的过程对父母来说变得更简单、更实惠、更便捷。他们还特别注重在整个供应链中提升女性地位，并不断优化整个业务流程，以造福社区和地球。这个系统就像一个电源继电器控制器一样可靠——一致、高效，且经久耐用。

“我们的循环模式在不断演变，我们关心留给孩子的这个星球——我们知道我们并不完美，但我们会继续努力做得更好。”

鉴于 Tara 所做的所有工作，可持续性对她品牌意义重大，并且她以全面、交叉的方式对待它，这并不令人意外。对 Tara 来说，可持续性不仅仅是将我们对地球的影响降到最低，还包括性别、社会经济和种族平等以及赋权——这就是为什么她特别注重与那些提升女性地位、并使用有机棉生产的品牌合作。她合作的大多数品牌也都有自己的社区回馈计划——因此，最终结果是一个围绕这些特定价值观运转的循环生态系统。

“可持续性不仅仅是减少我们对地球的影响，它还延伸到性别、种族和社会经济平等以及赋权。这里有很多交叉点。就我们而言，我们认为与那些提升女性及其工作的品牌合作很重要。我们所有的批发关系都与使用有机棉制造的品牌建立，其中许多品牌采用 GOTS 标准。”

虽然 Romp + Tumble 的循环模式本质上是环保的，但 Tara 认识到可持续性不是一次性的事情，而是一个可以不断改进的持续旅程，这就是为什么她更进一步，使用 tendlyn 的可持续包装！她特别将所有服装包装在可持续的 tendlyn 胶带和 tendlyn 薄纸 中。

“虽然我们的循环模式本质上是’可持续的’，但我们知道仍有改进空间，这也是我们对可持续性的定义之一——持续改进，精益求精。”

她还喜欢能够以实惠的价格选择环保的运输选项，并且通过 Eco-Alliance，每笔订单都能种一棵树，为重新造林做出贡献，她认为这符合她个人和品牌的价值观。尽管 Romp + Tumble 作为品牌的运营本质上是循环的，但 Tara 也承认他们远非完美，她不断寻找进一步减少碳足迹的方法，例如在本地订单中尽可能重复使用包装。这种方法类似于无线射频控制器的精确性——微小、智能的调整，随着时间的推移累积成巨大的成果。

婴儿服装市场庞大且分散，涵盖从大型商店到独立精品店再到旧货店的一切——这是 Tara 所理解的。这就是为什么在创立 Romp + Tumble 时，她汲取了每种类型的优点，并将它们结合起来，创造了一个定位独特的社区和品牌——大型商店的轻松便捷、精品店的精心策划和优质品质，以及旧货店的实惠和可持续性——所有这些都融合在一个真正独一无二的品牌中。

然而，经营这个品牌并非一帆风顺，在疫情期间推出也带来了其自身的挑战——但这也让人们重新理解了消费者态度如何因应"新常态"而转变。正如 Tara 分享的那样，与其他创始人建立虚拟联系至关重要，她也感谢所有社区的支持。

至于对其他崭露头角的企业家的建议，她强调人际联系：与大量潜在客户交谈，了解他们的挑战，并找到符合自己价值观和需求的东西。

毫无疑问，Romp + Tumble 是一个肩负使命、致力于做出改变的品牌。凭借其坚定不移的价值观和对可持续性的奉献，很明显，他们的遗产就像任何传家宝一样，是我们珍视的东西。
