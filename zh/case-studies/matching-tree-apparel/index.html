Matching Tree Apparel：为您和家人精心制作的道德服饰

Tuesday, September 01, 20201 分钟阅读

Matching Tree Apparel：为您和家人打造的环保服装

“我想向世界证明，商品可以来自可持续的来源，而不以人类自由为代价。"——Matching Tree Apparel 创始人 Tracey Szynkaruk

来源： https://tendlyn.com/imprint/matching-tree-apparel/ 作者： tendlyn 发布时间： 2020-09-01T03:55:08.000Z 阅读时间： 4 分钟

母亲是一个非常特殊的角色；她们塑造、鼓励并激励孩子成就大事，同时创造属于自己的美好生活。

认识 Tracy Szynkaruk，一位充满爱心的母亲，也是 Matching Tree Apparel 的创始人——这是一个位于不列颠哥伦比亚省、专为全家人打造的可持续服装品牌。

我们有机会与她交谈，她阐述了成为环境可持续且道德品牌的重要性。

以下是 Tracey 的原话：

“大家好！我们是 Matching Tree！我们位于加拿大不列颠哥伦比亚省内陆小镇 Grand Forks。我们是一家小型家族企业，致力于为成人和儿童制作配套服装。我们的重点是国内制造和可持续生产的服装，这样消费者就无需再三考虑购买行为背后的道德影响。我们的产品由美国境内获得公平工资的成年人制作。

我们创立公司，是因为我们不断壮大的家庭以及对消费的看法。作为一位母亲和公司运营的推动力，我想在陪伴一岁孩子的同时创造一些东西。另一个孩子即将出生，我想以身作则，教导我的儿子们：你可以通过道德、可持续、本地化且正直的方式在生活中取得成功。我想向世界证明，商品可以来自可持续的来源，而不以人类自由为代价。我们的商业模式利润微薄，但利润必须让位于人。”

“我们的愿景是打造从袜子到泳衣等一系列服装，供家庭享受。我们认为，通过配套服装，孩子与成年榜样之间可以形成美好的联系和纽带。我们也希望说服人们，并以身作则，证明在北美制造、支持本地经济、提供优质就业岗位是可行的。”

“我们迄今为止遇到的最大挑战是攒钱起步。之后，就是向人们展示道德生产的产品成本更高。价格包含了工人的生活工资、对环境的考量以及可持续生产，同时还要跟上美国的经济增长。海外生产的产品通常不考虑生活工资、工人权利、当地污染或可持续性。我们应对的方法是，知道有越来越多的有意识消费者不愿支持现状，他们明白花的每一分钱都是在为正确而非廉价的东西投票。我们也知道，我们的工作质量更高、更耐用，会带来回头客。我们给其他人的建议是：坚持下去，相信你的产品，并且根据需要多次回到绘图板，直到做对为止！”

“我们前进的动力来自于我们对正确事物的认知，以及我们想为孩子树立的榜样。我们知道，为了让人类拥有未来，我们需要开始从全球视角看待我们的环境。如果我们想要为环境、孩子和国家经济争取未来，就必须将制造业带回本土。我们不能继续用环境破坏和化石燃料运输商品来补贴利润。一切都需要尽可能本地化。北美是一个好的开始！

可持续性对我们很重要，因为我们希望为孩子们创造一个可以享受的世界。这对我们的品牌和业务意味着，我们赚的钱更少，但我们做的是正确的事。从生产到包装和运输，我们尽一切努力使用可生物降解或可回收的产品。

作为一家企业，我们以尽可能降低环境足迹的模式起步。我们的产品采用美国种植的材料制成。我们不在海外制造并全球运输产品，而是依赖美国本土更高质量的制造。这减少了排放。此外，我们向客户展示，我们所有的运输材料和包装要么完全可堆肥，要么可回收。”

“我们选择定制包装，是因为我们提供高端优质产品。我们认为，消费者会看重一件以定制包装送达的高端本土制造产品。我们从 tendlyn 选择的产品包括可堆肥邮寄袋、可回收贴纸和薄纸。这些产品使我们能够继续践行愿景：从制造到送达客户家门口，为消费者提供道德且对环境负责的产品。他们无需再三考虑整个过程中的道德问题。”

“我们选择 tendlyn，是因为我们从他们的网站上看到，我们这家小型初创公司与他们共享许多相同的价值观。我们明白，一次性包装选项可能带来更高的利润率。我们想支持另一家以身作则、开拓创新的公司，证明可持续和道德的商业是可行的，而且可以做得很好！”

Matching Tree Apparel 趣闻：

“如果我能获得一种超能力来改善地球的现状，我希望是光合作用。这样，作为一家企业，我可以用它来清除大气中的二氧化碳。”

“Matching Tree 是一家由母亲经营的公司。Tracey 一手抱着她一岁的孩子，一手拿着袜子，同时管理着网站、在线商店、包装、订单和发货以及账目。

致所有其他辛勤工作的母亲们，我们想让你们知道，你们所做的一切并不容易，你们太棒了！”
