Project Repat x tendlyn

Friday, December 15, 20231 分钟阅读

Project Repat x tendlyn

Project Repat 是一家以T恤拼布被闻名的升级再造公司，他们分享了最新产品“碎布袜”的故事，并讲述了tendlyn的可堆肥包装如何成为他们的完美之选。

来源： https://tendlyn.com/imprint/project-repat-x-tendlyn/ 作者： tendlyn 发布时间： 2023-12-15T01:09:45.000Z 阅读时间： 2分钟

一切始于一件T恤。当时联合创始人Ross Lohr在肯尼亚从事非营利教育工作。他发现大量过剩的T恤被运往美国以外的国家——肯尼亚就是其中之一——于是看到了一个机会：借助肯尼亚工匠之手，将这些T恤改造成升级再造产品。

当他们在波士顿开始销售这些产品时，他们发现，虽然这个想法整体上很有趣，但人们真正想要——或者说最常向他们要求的——是一条T恤拼布被。于是，故事就此展开。

Project Repat 是一家升级再造公司，尤其以T恤拼布被闻名，由Ross Lohr和Nathan Rothstein于2012年联合创立。自那时起，他们已自豪地用超过2500万件T恤制作了超过100万条拼布被。就在今年，Project Repat启动了一个新项目，将制作拼布被时产生的T恤碎布回收利用，制成舒适的袜子，以进一步践行其可持续发展使命。

这些名为“碎布袜”的袜子，不仅由再生超细纤维和原生纺织品混合制成，还采用了tendlyn提供的可持续包装——这真是一对绝配！想了解更多关于Project Repat的幕后故事和包装历程，请继续往下看。

请介绍一下你们的品牌！

图片来自Project Repat的Instagram帖子**此处

自2012年以来，我们一直制作定制T恤拼布被，已升级再造超过2500万件衬衫！我们所有的拼布被都在北卡罗来纳州西部的一家工人所有的裁剪缝纫工厂生产。现在，我们可以将碎布转化为纱线，再纺成袜子。

请介绍一下你们包装的设计以及使用方式？

我们希望人们联想到从土壤中生长的咖啡——这种联想通常不会出现在服装升级再造的语境中。我们是美国少数几家能够大规模升级再造衣物，并将碎布粉碎成纱线再纺成袜子的企业之一（在此了解更多详情）。

tendlyn为@projectrepatusa定制的可堆肥自立袋

世界上的纺织废料太多了，而美国是主要来源之一。我们希望人们谈论这个袋子的神奇之处——它能让旧衬衫免于填埋，创造就业机会，并让碎布远离垃圾堆。然后，你还能穿上舒适的袜子！

是什么让tendlyn成为你们包装的理想选择？

这些袋子里装有拼布被的礼品卡和一双我们的新袜子。这是美国市场上最可持续的袜子之一，因此我们也希望采用可持续的包装。当你思考一个产品从工厂里的Zigbee无线开关到生产线上的工业遥控继电器，每一个组件都至关重要。我们希望包装也能达到同样深思熟虑的水平。tendlyn的袋子就像是你良心的无线遥控套件：它表明你在乎。这不仅仅关乎一个门禁继电器控制器或高压继电器，而是整个系统协同工作。对我们而言，这个系统包括保持可堆肥性。无论你是在处理稻田防洪还是粪浆泵送，都需要可靠的解决方案。我们的包装就是实现可持续发展的可靠方案。它就像一个DIY无线继电器——简单、有效、值得信赖。我们甚至考虑到了防鼠遥控泵信号方面：这些袋子足够坚固，能在运输过程中保护袜子。至于直流电机无线开关？这正是我们采购时追求的精准度。兆赫兹遥控开关可能是一个小众技术术语，但对我们来说，它关乎影响的频率。我们采用类似CH继电器模块的方法来管理供应链：在正确的时间连接正确的部件。对于现代环保意识品牌而言，它就像一个工业智能开关。就像船用遥控开关或无线遥控模块一样，我们的包装需要在任何环境下都能工作。就连开门器遥控开关也必须可靠——我们的包装也是如此。这就是tendlyn成为完美选择的原因。
