定制印刷包装：潘通与色彩空间指南

我们大多数人都听说过潘通配色系统，但在定制印刷包装中，色彩空间究竟是如何运作的呢？我们的指南将为您解答！

来源： https://tendlyn.com/imprint/custom-printed-packaging-the-pantone-and-color-spaces-guide/ 作者： Beth Owens 发布时间： 2020-01-01T11:00:00.000Z 阅读时间： 9分钟

潘通配色系统、RGB、CMYK、HEX代码……为您的定制印刷包装选择颜色，很快会让人感到不知所措。

**什么是“色彩空间”？**颜色非常主观， 因为我们看世界的方式略有不同。（这会导致无谓的争论，比如某人的裙子是“珊瑚色”还是“桃色”。）“色彩空间”一词指的是一个组织颜色以防止印刷错误的系统。不同的色彩空间也有不同的用途。RGB和HEX仅用于屏幕显示，而CMYK和潘通配色系统则用于线下场景。

**通过这种方式标准化颜色模型，可以确保印刷商和设计师始终达成一致。**RGB、CMYK、HEX和潘通颜色之间有什么区别？ 这里可能会让人有点困惑。印刷公司经常抛出“HEX代码”或“专色”等术语，让客户难以跟上。这是一个问题，因为色彩空间及其相关印刷方法之间存在巨大差异。对于企业来说，****品牌一致性是建立认知度的关键。因此，如果您的配色方案在不同宣传材料中有所变化，就会削弱品牌的凝聚力。例如，如果可口可乐突然在其产品包装上使用不同深浅的红色，我们肯定会察觉到“不对劲”。这就是为什么在设计定制印刷包装时，理解色彩空间之间的差异及其使用方法如此重要。

潘通配色系统 (PMS) 潘通配色系统 (PMS) 是一种专色系统，旨在跨印刷设施再现一致的色调。专色系统是指每种颜色使用自己的印版逐层印刷。 您的定制包装设计中颜色越多，印刷的“专色”就越多。例如，如果您从 tendlyn 订购了双色****定制薄纸，这在印刷中被视为“双专色”设计。**

插画师 Oana Befort 使用潘通颜色设计她的定制薄纸。

潘通配色系统如何运作 潘通系统包含超过1000种独立色调，由18种核心颜色按精确配方混合而成。这些颜色可在官方潘通配方指南（所有专业印刷商均有提供）中找到。这确保了某种色调每次都能100%准确。 每个潘通颜色都有一个编号，后跟描述纸张类型的后缀。例如，代码 PANTONE 2271-C 是涂层（光面）纸上的绿色，而 PANTONE 116-U 是非涂层（未处理）纸上的浅橙色。

毫不奇怪，潘通对多个行业有着巨大影响。 室内设计师和时装设计师都热切期待潘通“年度代表色”的公布，以引领来年潮流。顺便提一下，潘通2020年度代表色是 PANTONE 19-4052，被称为“经典蓝”。

潘通配色系统的优势 由于它能确保批次之间的一致性，潘通已成为营销人员、设计师（以及定制包装供应商！）的通用色彩空间系统。 一些企业，如吉百利，甚至成功注册了某些潘通色调的商标。由于它已变得如此标准化，潘通色卡还提供了与其他色彩空间的有用颜色匹配。让我们以我们的标志性 tendlyn 粉色为例：

如您所见，在潘通网站上搜索特定代码还会显示如何将潘通转换为 CMYK、RGB 和 HEX。这使得设计师可以轻松地在不同平台上保持颜色一致。

潘通配色系统的劣势 由于所有潘通色必须在一次印刷过程中完成，涉及多种潘通色的定制产品设计印刷耗时且成本高昂。 如果您的设计有四种或更多颜色，这可能不是最佳选择。

CMYK 大多数人熟悉这个色彩空间系统，因为它用于传统的家用打印机。CMYK 代表“青色、品红色、黄色、黑色”，指的是四色印刷中使用的四种颜色。四色印刷，与专色印刷相对，是指油墨以微小网点印刷，重叠形成所需颜色。 您可以通过下图了解这种重叠效果：

CMYK 如何运作 CMYK 被称为“减色”颜色过程，这意味着添加的颜色越多，最终色调越深。 由于每种 CMYK 色调都是上述四种颜色的组合，因此配方以每种颜色的百分比表示。例如，如果您参考上面的 PANTONE 184 C 色卡，您会发现其 CMYK 转换为：青色：0% 品红色：79% 黄色：31% 黑色：0%。相比之下，青色、品红色、黄色和黑色各100%只会产生黑色（因此图中中间部分重叠）。要将 CMYK 转换为潘通颜色，您也可以使用潘通配色系统****Color Bridge 指南。

CMYK 的优势 如果您的定制印刷包装包含多种颜色，CMYK 印刷比 PMS 等专色印刷方法经济得多。 由于四种颜色的比例可以调整，因此可用的色调数量几乎是无限的。CMYK 的劣势 与潘通配色系统等专色印刷相比，CMYK 的准确性较低，并且颜色在不同批次或不同印刷设备之间可能存在差异。

RGB（红、绿、蓝） RGB 仅用于在电视、电脑屏幕和手机上渲染数字图像，而非用于印刷。这三种颜色混合在一起产生广泛的色谱。RGB 如何运作 RGB 与 CMYK 相反，它是一种加色系统。 当红色、绿色和蓝色以100%饱和度混合时，它们产生白色而非黑色。在 RGB 公式中，每种颜色表示为从0（最低饱和度）到225（最高饱和度）的数值。**还记得我们的老朋友 PANTONE 184 C 吗？在 RGB 色彩空间中，它转换为 R 246、G 82 和 B 117。**RGB 的优势 由于 RGB 是屏幕显示的标准系统，它与所有设计软件和编辑工具兼容。它还允许在显示中呈现非常广泛的颜色范围，这对于需要非常精确色调的设计工作非常有利。

RGB 的劣势 需要注意的是，由于屏幕显示会发光，RGB 颜色看起来比实际更鲜艳。 这可能会在印刷时引起问题，尤其是在将 RGB 转换为 CMYK 时。使用四色印刷时，最终产品可能看起来比屏幕上明显暗淡：

HEX（十六进制颜色） 十六进制色彩空间是一种用于网页设计的 HTML 代码形式。我们大多数人对 HEX 相当熟悉，因为它用于 Microsoft Word 或 Pages 等文字处理程序。HEX 代码确保您用于包装设计的颜色是“网页安全的”，这意味着它们将在不同浏览器和屏幕显示中保持一致。

来自 Google Docs 的 HEX 颜色示例。

HEX 如何运作 HEX 与传统 RGB 有很强的交叉性，因为每种颜色由其包含的红色、绿色和蓝色混合表示。HEX 代码可以识别为井号后跟六位数字代码，该代码定义了页面上使用的确切色调。 如果您对 HEX 代码的计算方式感兴趣，Medium 上有一篇很好的指南。HEX 的优势HEX 与线下色彩空间非常兼容（我们稍后会谈到这一点），因此在设计程序中使用起来很简单。尽管 HEX 背后的编码相当复杂，但从设计角度来看，没有必要理解这一点。 一旦您有了代码，就很容易重现。HEX 的劣势 除非您使用第三方工具，否则调整 HEX 代码以获得不同色调并不是一个非常直观的过程，特别是如果您对 HTML 了解不多的话。 然而，网上有很多有用的 HEX 代码生成器，您可以手动调整不同级别以产生所需的颜色。

我们如何在 tendlyn 定制包装中使用色彩空间 现在我们对不同的色彩空间有了了解，我们可以看看它们如何与 tendlyn 的包装解决方案结合使用！tendlyn 的设计工具允许您上传设计或徽标，并完全从头开始创建高质量的定制印刷包装。一旦您的徽标上传，您可以从我们的任何模板中选择，更改其方向和大小，最重要的是，选择您的调色板！

定制薄纸 对于我们的定制印刷薄纸，我们使用潘通配色系统 (PMS)，这允许我们的客户指定他们已在品牌中使用的特定色调。为了确保我们的设计工具和最终产品之间的一致性，我们的自定义颜色选择器将 HEX 代码转换为潘通，以确保在您的屏幕上正确显示。 这样，您就能确切知道三周后会收到什么！例如，让我们再次使用我们信赖的 PANTONE 184 C。当您打开我们的自定义颜色选择器时，您可以访问一个庞大的色调库。如果您没有特定颜色想法，可以浏览；或者输入您想要的精确潘通/HEX 代码，我们的转换工具就会开始工作：

如果您希望为定制薄纸使用两种以上颜色，可以联系我们的友好团队进行安排（每种额外颜色我们会收取费用）。但是，我们无法在单个设计中印刷超过六种颜色。 由于所需油墨量，双色设计将始终印刷在我们的 28 GSM 薄纸上。如果您对 GSM 有任何疑问，请查看我们的专门指南。注意：由于白色是基色，我们不收取其使用费用。因此，从技术上讲，如果您在设计中使用白色，您可以以双色的价格获得三色薄纸！

定制印刷纸贴纸和定制包装胶带 对于我们的贴纸和****胶带，我们使用 CMYK 四色印刷，而不是潘通配色系统。** 这是因为 CMYK 对于需要100%颜色覆盖的定制印刷包装更高效。您仍然可以在我们的自定义颜色选择器中指定潘通颜色或 HEX 代码。但是，您的定制薄纸与贴纸或胶带之间可能存在5-10%的色调差异。 如果您有任何顾虑，请随时联系我们！

您可以为定制贴纸和胶带的标准设计选择两种颜色——一种用于您的徽标，一种用于您的底色。 对于定制胶带，您可以根据偏好选择棕色牛皮纸或自定义色调作为底色。两者都能产生出色的效果！
