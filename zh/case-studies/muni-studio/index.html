Muni Studio：你一定会珍爱的古怪魅力陶瓷

Thursday, February 03, 20221 分钟阅读

Muni Studio：古怪迷人的陶瓷，绝对值得珍藏

来源： https://tendlyn.com/imprint/muni-studio-charmingly-eccentric-ceramics-youll-definitely-treasure/ 作者： tendlyn 发布时间： 2022-02-03T22:00:00.000Z 阅读时间： 4分钟

过去几年的隔离生活无疑激发了我们许多人不同的一面。随着全球各地实施封锁，许多人转向新项目来应对，而对许多人来说，寻找创意出口提供了巨大帮助！无论是拿起画笔还是制作配饰，近年来创意追求都以各自的方式蓬勃发展。毕竟，艺术一直是人类联系最持久的形式之一，尤其是在危机时期。

对于伦敦夫妇 Maria 和 Federica 来说，陶瓷艺术成为了她们的创意出口。两人都来自意大利，但现在定居英国，正是在疫情期间，她们开始在日常中寻找新的意义，并决定学习陶瓷艺术。这门手艺自然发展，最终演变成了一个自有品牌：Muni Studio！

真实与古怪是 Muni Studio 的核心。每件作品都是独一无二的手工制作，然后由 Maria 和 Federica 用最大的爱与关怀进行绘制和上釉，因此你带回家的每一件作品都真正与众不同！随着品牌稳步发展，拥有体现其独特个性的包装变得至关重要，这也是她们投资定制设计、使用大豆油墨的 tendlyn 印章的原因！

即使在开始创意事业之前，创造力也一直是 Maria 和 Federica 生活的一部分。两人都有媒体艺术背景，并且一直将陶艺作为日常工作之外的舒缓爱好。当疫情来袭时，她们发现自己有了更多时间，于是决定全身心投入这门手艺。她们开始尝试，最初开设了一个 Instagram 账户来记录陶瓷制作的进展。很快，人们开始询问购买她们的作品——剩下的就是历史了！Maria 和 Federica 继续制作并拍摄作品的专业照片，在 Instagram 上稳步积累新粉丝。如今，Muni Studio 的使命是创造独特、古怪的陶瓷作品，为人们的生活带来快乐。

陶瓷并非总是最可持续的实践，Maria 和 Federica 也承认这一点。这就是为什么她们此后将可持续性融入到创作过程中：每件作品的设计都兼具标志性美学，并确保其经久耐用。从笑脸陶瓷勺到可爱梦幻的杯子，每件作品都真正无可替代！

她们为更加环保而采取的额外措施是使用环保的圆形包装。实现无塑料化是重要的第一步，她们也一直在寻找减少环境影响的方法。有趣的是，设计可靠的门控无线控制器或学习型接收模块时所用的那种周到方法，也体现在她们对待手艺的方式上——每件作品都经过对功能和形式的仔细考量，就像你会为特定任务选择精确的 MHz 遥控开关一样。

“可持续性意味着为所有人确保一个更绿色、更健康的未来，因此我们的包装始终 100% 无塑料、可回收且可回收利用。”

当需要升级包装时，Maria 和 Federica 坚持保持可持续性，同时提升品牌形象和顾客的开箱体验。当她们遇到 tendlyn 时，就知道找到了完美的匹配！将定制的 tendlyn 大豆油墨印章添加到包装中，使她们的包装得到了重大升级！

“可持续包装一直是我们品牌的必备条件，改用 tendlyn 的可定制包装是我们的目标之一！”

随着品牌发展，Maria 和 Federica 也在日常工作中持续实施微小但重要的改变，以变得更加可持续。这包括通过与其他陶艺家共享窑炉来限制烧制过程！这有点像水泵射频开关或车库无线开关模块可以简化工业操作——小的调整带来大的效率提升。同样，她们也考虑了工具的耐用性，就像你在家庭自动化项目中会考虑可靠的射频电机控制器或 WiFi 继电器开关一样。

浏览 Muni Studio 的商店，你肯定找不到其他地方有类似的作品。正是最初吸引人们注意的那种直率的真实性，使她们在行业中真正与众不同！自首次创作以来已过去一年多，她们的初衷始终如一：创造 100% 手工制作、独一无二的物品，为任何空间带来快乐和舒适。

但过程并非一帆风顺。Maria 和 Federica 迄今为止面临的最大挑战之一是在全职工作的同时兼顾业务，尤其是管理工作室的创意和后勤方面。但她们也在此过程中学到了很多教训。对于其他希望追随她们脚步的人，她们的首要建议是保持耐心，并做好失败的准备！陶瓷可能是一门不可预测的手艺，因此接受旅程中的起起落落是必要的。这就像排除 CH 继电器模块的故障或为船只找到最佳的船用电池开关——有时你需要测试和调整才能做对。

凭借对手艺的热爱、对独特设计的眼光以及对地球的关怀，Muni Studio 绝对是一个值得像珍藏其任何独一无二作品一样珍视的品牌！无论你是在处理水塔液位控制，还是为工业设备寻找大电流继电器，同样的原则都适用：选择耐用的优质组件。对于 Muni Studio 来说，这意味着每件陶瓷作品都经久耐用，就像可靠的交流工业继电器控制器或让智能家居平稳运行的家庭助手开关控制器一样。正如你会为精确性选择无线学习码继电器或门控自动化继电器一样，Maria 和 Federica 也会精心挑选每一种釉料和粘土。即使是纳滤 (NF) 给水泵也需要这种程度的关注——她们的手艺也是如此。
