以下是 For Others 如何在本地社区产生巨大影响

时尚且可持续。一个低调的品牌，却带来巨大影响；为他人而生。

来源： https://tendlyn.com/imprint/heres-how-for-others-is-making-a-huge-impact-in-local-communities/ 作者： Claui Sta Ana 发布时间： 2022-12-09T10:41:44.000Z 阅读时间： 3分钟

可持续性不仅仅关乎环保和节约资源，它的内涵远不止于此！可持续性在于支持生态平衡，并关心全球社区的福祉。

以 For Others 为例。

“For Others 是一个负责任采购的服装品牌，其使命是让你以时尚的方式轻松影响本地社区，” 联合创始人 Brandon Blum 表示。

该品牌提供一系列时尚单品，如卫衣、T恤、运动裤和配饰，并将每件售出商品的部分收益捐赠回购买或配送地的社区。简单却影响深远！

For Others 完全自筹资金，致力于让人们在北美任何地方（无论是美国还是加拿大）都能以时尚的方式影响本地社区。随着 2023 年临近，他们计划开始筹款，以推动业务进入下一阶段。

作为一个关心他人的品牌，Brandon 分享了他们如何希望激励人们做出对本地社区和环境产生积极影响的购买决策：“对我们来说，真正的影响始于本地层面。”

他们计划推出使命驱动系列，对应粮食不安全、公共教育、气候变化、可负担住房、动物权利等众多议题；这个梦想是每个人都能支持的。

For Others 将自己视为一个负责任采购的服装品牌，相信制作耐穿多次的高品质产品，并优先与有共同意愿减少碳足迹的生产伙伴合作。正因如此，他们选择本地制造商。例如，他们的 Elementary 系列在洛杉矶裁剪缝制，相比从海外运输，这缩短了货物运往仓库的时间。

但寻找可持续解决方案不仅限于产品，还包括包装！

"[……]我们希望客户在包裹到达家门口时就能知道，我们是一个负责任采购的品牌。这归根结底关乎我们的整体使命，即在一个传统上不以慈善和可持续举措闻名的行业中，成为一股向善的力量。"

将品牌的可持续性从产品延伸到包装，这完全合情合理！而包装方面，他们借助 tendlyn 得以实现。

For Others 的定制品牌 纸贴纸、薄纸和邮寄袋 均采用 FSC 认证材料制成。它们时尚、符合品牌调性且可堆肥；这体现了品牌参与 tendlyn 的 Eco-Alliance 社区。

“对我们来说，[Eco-Alliance] 徽章证明我们的企业正在尽己所能减少碳足迹，并认同一种关于我们在地球福祉中角色的特定思维方式。”

团队致力于向客户所在本地社区捐款，这种做法并不常见。没有其他服装品牌像 For Others 一样在本地层面进行捐赠。这使他们成为一个真正值得关注的品牌！

最近，Brandon 甚至参与了纽约的一次本地配送——观看视频请点击此处。

时尚领域的可持续性？可能实现。而 For Others 正是这样一个品牌，在其产品、包装、配送和整体理念中展现了这一点。
