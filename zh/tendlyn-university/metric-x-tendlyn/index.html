Metric x tendlyn.

Tuesday, March 03, 20261 分钟阅读

Metric x tendlyn.

一家芝加哥咖啡烘焙商，一砖一瓦地建立起长达十年的业务，没有投资者，没有董事会，也没有捷径。

来源： https://tendlyn.com/imprint/metric-x-tendlyn/ 作者： tendlyn 发布时间： 2026-03-03T02:15:14.000Z 阅读时间： 5分钟

Xavier Alexander 从事咖啡行业已超过25年。90年代末，他在奥兰多的星巴克开始工作，靠轮班赚钱，以资助他真正的目标：成为一名巡演音乐人。乐队没做成，咖啡却成了他的事业。

到2002年，他迷上了烘焙。他是朋友圈里那个喋喋不休谈论新鲜烘焙豆子、本地小型烘焙商以及新鲜度福音的人。十年后，他成为芝加哥Intelligentsia的烘焙经理，在90公斤级的烘焙机上每天处理15,000到25,000磅咖啡。

那是个大业务。但不是他的。

一砖一瓦

大约在2010年，Alexander遇到了Darko，后者拥有一家名为Café Streets的咖啡馆。Darko是芝加哥最早的多品牌烘焙商之一，在其他人还不知道Heart、Verve和Four Barrel这些西海岸年轻公司时，他就引进了它们。他不是在追逐潮流，而是在追求品质。

他们一起喝了杯啤酒，聊了聊自己创业的事。Alexander有烘焙技术，Darko有咖啡馆。他们买了一台烘焙机，在Alexander保留本职工作的同时，兼职干了一年，于2013年在偏远郊区的一个车库里推出了Metric。

从第一天起的模式就是：买一袋咖啡，卖掉，再买三袋。没有投资者，没有董事会，没有外部资金。只有两个人，一点一点地建设。这很像第一次给车库遥控开关接线——边做边学，每接好一个连接点都让你感到自豪。

“我们是DIY的，我们是独立的，从这个意义上说，我们更像朋克摇滚，”Alexander说。“从表面上看，人们看到我们的品牌，无法根据我们的品牌和推广方式来评估这一点。但我们为自己是真正意义上的独立而深感自豪。”

十年的漫长岁月

独立是有代价的。没有资金就意味着没有钱。Alexander有妻子和三个孩子。打造Metric意味着漫长的白天、更长的夜晚、远离家人的时间，以及那些不会出现在品牌故事里的内心挣扎。

“从某种程度上说，这是成功的，也是令人愉悦的，”他说，“但同时也非常艰难，极其困难。”

最初的咖啡馆并非世界一流。它本意也并非如此。愿景始终更长远：打好基础，买下一个仓库，把事情做好。这花了十多年时间。

2016年，他们在芝加哥West Town的烘焙厂角落开了一家400平方英尺的外带咖啡馆。顾客可以通过玻璃隔板观看生产过程。它很小，经过深思熟虑，并且是他们亲手建造的。

然后，Milli来了。

Milli

Milli是新店。位于Avondale的一家全天候咖啡馆和面包店，提供精品咖啡、糕点、时令美食和精选葡萄酒单。它位于Metric现在拥有的一个仓库内。

他们用SBA贷款买下了这栋楼。他们自己动手装修。负责设计和项目管理的Darko设计了整个空间。装修花了三年时间，因为他们负担不起赶工的费用。大多数人八个月就能翻新一个空间。Metric按照自己的时间表，用自己的钱，一砖一瓦地完成。这就像在旧建筑中安装工厂无线开关时所需的耐心——你不能偷工减料，因为捷径会导致失败。

“我的商业伙伴Darko在从规划到项目管理再到设计的各个方面都非常精通，”Alexander说。“他亲自设计了整个空间。我们为此感到非常自豪。”

结果就是一个看起来像是来自资金充裕的企业的空间。但事实并非如此。它来自于十年间对捷径说“不”的坚持。

由人类制造

这句标语来自曾在Intelligentsia工作的设计师Tim Breen。当Metric在确定品牌形象时，Breen提出了这个建议：由人类制造。

他们采纳了。然后，有一段时间，他们又搁置了。这感觉太直白了。有些人还开了玩笑。但Alexander年纪越大，就越认同这句话。

“在一个充满AI、数字媒体以及信息和营销过载的世界里，我认为‘这是由人类制造的’这个提醒将永远站得住脚，”他说。

这句话出现在咖啡杯上、随行杯上、包装上。它不是一句口号。它是关于公司运营方式的事实陈述。

伊利诺伊州唯一一家

Metric是伊利诺伊州唯一一家获得BCorp认证的咖啡烘焙商。这不是炫耀，而是一个工具。

Alexander在遇到其他本地BCorp公司后，被它们对文化、福利和责任的关注所打动，于是寻求认证。BCorp为Metric提供了一个框架：要达成的基准、要遵循的指导方针，以及一个与业务无利害关系的第三方来验证他们的运营方式。

tendlyn 定制冷饮杯，由 @metriccoffee 设计

“你不需要获得BCorp认证也能做到这些，”Alexander说。“无论有没有认证，你都可以做所有这些事。但认证的作用是，它提供了一个第三方来审查你的经营方式。”

他们的分数不是最高的。有些拥有室内健身房和保姆服务的科技公司能拿到120分。Metric还没到那一步。他们把一切都投入到了基础设施上。下一阶段是系统、材料和人员。

罗马不是一天建成的。Metric也不是。

属于这里的东西

Milli的前厅经理Mo最近说了一句话，让Alexander印象深刻。他们在做品酒活动时，Mo说：“这里没有一款酒是不该出现的。”

Alexander对咖啡也有同样的看法。这里没有一款咖啡是不该出现的。他们是品味创造者。他们选择每一颗豆子，是因为他们喜欢，并且知道顾客也会喜欢。同样的道理也适用于糕点、葡萄酒和菜单上的所有东西。

tendlyn 定制手提袋，由 @metriccoffee 设计

“无论‘可持续’对他们意味着什么，我们的包装和生产都应用了一些可持续性因素，”Alexander说。“我们这里的东西不便宜，也无意做得便宜。”

目标很简单：当有人拿着一袋Metric咖啡或走进Milli时，感觉应该是好的。真正的好。由在乎这一切的人类制造。
