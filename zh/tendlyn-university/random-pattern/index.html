加拿大设计工作室Random Pattern的一天！

Friday, February 04, 20221 分钟阅读

加拿大设计工作室 Random Pattern 的一天！

“Random Pattern 这个名字源于我的硕士论文。它关乎信息的含义，以及每一条信息都是模式与随机性的混合体。我喜欢认为每个品牌，就像每个人一样，都是模式与随机性的混合体，这让我们独一无二。”——Pili

来源： https://tendlyn.com/imprint/a-day-in-the-life-of-canada-based-design-studio-random-pattern/ 作者： tendlyn 发布时间： 2022-02-04T00:00:00.000Z 阅读时间： 4 分钟

本期我们推出博客系列“Wrap”，聚焦 tendlyn 创意社区中一些杰出的成员。这个“一天的生活”系列将特别介绍一位创意人士，展示他们的创意工作空间和日常作息。继续阅读，一窥 tendlyn 创意人的“一天”！

Pili Fernandez Davila 是一位品牌与网页设计师，也是 Random Pattern Studio 的创始人。她来自秘鲁，但移居加拿大并在那里生活了 9 年。Random Pattern Studio 是一家设计工作室，致力于通过有意义的定制化品牌和设计，帮助有使命感的公司成长并实现目标。他们的使命是打造能够助力公司目标与宗旨的设计，同时与客户建立并创造有意义的联系和体验。

Pili 最初学习的是广告专业，但在大学第一次暑期实习期间，她意识到设计才是她的使命，从此便未曾停止设计。她最初为广告活动做设计，但很快转向了品牌和网页设计。Pili 曾在秘鲁老家开设了一家名为 Café con Leche（牛奶咖啡）的设计工作室，并在五年内专注于与本地及国际的大小品牌合作。

Pili 于 2013 年移居加拿大攻读设计硕士学位。完成学业后，她在多家公司担任设计团队负责人。她最终决定放手一搏，开设了自己的设计工作室——Random Pattern 由此诞生！倾听企业主和创始人的故事是她的灵感源泉，也是她渴望与小企业合作的驱动力之一。

“Random Pattern 这个名字源于我的硕士论文。它关乎信息的含义，以及每一条信息都是模式与随机性的混合体。我喜欢认为每个品牌，就像每个人一样，都是模式与随机性的混合体，这让我们独一无二。”——Pili

“作为创意人士，我们可以从很多事物中获得灵感。我个人从家居装饰、电视节目和纪录片、餐厅以及书籍中寻找灵感。当然，也少不了神奇的互联网世界（Behance 绝对是我最喜欢的在线灵感来源！）。”——Pili

Pili 通过 20-30 分钟的锻炼开启清晨，随后梳洗打扮，再享受一顿悠闲放松的早餐来完美收尾——苹果配杏仁酱和香草果酱是她最近的早餐最爱！

她通常通过查看 Asana 和日历开始一天的工作，以了解当天的计划安排。她还会花几分钟回复客户的电子邮件和信息。Pili 喜欢将一天分成两到三个时段，并为每个时段分配特定任务。她发现将项目分解成小任务可以避免陷入困境和可怕的创意瓶颈。

“我在早上完成最具创意的任务，因为我 100% 是个晨型人。我会利用早晨的大部分精力来完成创意和动手工作（这绝对是我一天中最喜欢的部分）。我尽量每周安排两次会议，并且最好在一天结束时进行。周二和周四是我的无会议日，绝对是我一周中最喜欢的两天，因为我可以整天做设计。

我喜欢在午餐时休息一下，并在完成工作的过程中再休息几次。我使用自己版本的番茄工作法，通常以 45 分钟工作、15 分钟休息的时段进行。我并非总是遵循这个规律，但当我难以集中注意力时，这是一个好方法。”——Pili

Pili 在设计过程中最喜欢的部分是构思品牌和网站的初始概念。她喜欢探索各种设计和意图，直至那个灵感迸发的时刻。她希望确保自己的品牌设计有意义，并且每个网站都能为用户创造无缝的体验。她童年梦想成为卡通画家的愿望，常常通过使用手绘图标和插画在她的作品中得以体现。

一杯饮品（通常是一杯咖啡或一瓶水）和一本用于记录想法和草图的笔记本是 Pili 的必备品。她在设计时总会冒出其他项目的点子，因此总是随身携带笔记本，以便在不分心的情况下记下它们。

Pili 是通过 Instagram 上的广告偶然发现 tendlyn 的，并立刻爱上了它。她非常喜欢包装设计既有趣又色彩丰富，同时还具有可持续性。她与许多电商商店合作，并始终倡导可持续的包装理念和解决方案。

有趣的事实：Pili 实际上会讲三种语言——西班牙语、英语和德语（尽管她承认德语已经很久没练习了！）。她还养了一只名叫 Michelle O’bunny 的宠物兔，这个名字的灵感来自米歇尔·奥巴马。🐰
